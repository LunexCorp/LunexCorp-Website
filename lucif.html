Moderation

Under the hood

Small files, one command each

Lucif runs on Node.js with Baileys. Every command is a single file in a folder named for its category, and the bot loads them all on start.

  • Interactive buttons are routed by prefix, so a tap lands in the right command.
  • Accounts, items and violations live in SQLite.
