What Lucif does

Commands start with #. Send #menu in the chat to see them all.

  • Utilities

    Ping, QR codes, translation, flight lookups and a menu with buttons.

  • Economy

    Join, work, claim daily rewards, shop and climb the leaderboard.

  • Games

    Russian Roulette and Blind 40, a card game for 2 to 6 players.

  • Moderation

    Scam and abuse filtering that warns first, then removes repeat offenders.

Small files, one command each

Lucif runs on Node.js with Baileys. Every command is a single file in a folder named for its category, and the bot loads them all on start. Adding a feature means adding a file.

  • Interactive buttons are routed by prefix, so a button tap lands in the right command.
  • Accounts, items and violations live in SQLite.
  • Pushing to GitHub deploys the bot: Actions connects to the server, installs, and reloads it under PM2.
